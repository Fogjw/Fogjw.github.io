认识Go

Go语言（Golang）是由Google设计的一种静态强类型、编译型、并发型，并具备垃圾回收功能的开源编程语言。它旨在结合动态语言的开发效率和静态编译语言的安全性及性能，为解决现代软件开发中的规模化和并发问题而生。

Go的设计理念是以软件工程为导向，追求极致的简单、组合与高效并发。

概念了解了解就行了。

go.mod和包（package）

go.mod 是 Go 语言官方依赖管理工具 Go Modules的核心文件，定义了当前项目的模块（Module）信息及其所有依赖。

模块 (Module)：是 Go 依赖管理的基本单元。一个模块是一组 Go 包的集合，由项目根目录下的 go.mod 文件定义。每个模块都拥有一个唯一的模块路径 (Module Path) 作为其标识符。

包 (Package)：是 Go 代码组织的基本单元，即同一目录下的一组 .go 源文件的集合。

一个模块包含一个或多个包。一个包的导入路径 (Import Path) 就是 “模块路径 + 包所在子目录”。

变量与常量

Go 语言支持类型推断，使用:=，但是:=只能在函数内使用，var 可以在函数内外。Go 语法中类型写在变量名后面（如var x int）。

  • Go 语言编译器强制保证声明即初始化，所有变量在声明时，都会被显式地初始化为其类型的零值（Zero Value）。因此上面如var y int这样只声明没有赋值的变量，值为该类型的零值，这和 C/C++ 未初始化的变量可能是任意垃圾值不同。零值后面会讲。

基本类型与复合类型

Go 语言是强静态类型语言，变量类型在编译期间被严格确定，并且在程序运行过程中无法改变。类型之间的操作必须显式进行，编译器不允许隐式类型转换。

比如说，在 C/C++ 中，我们经常直接把非布尔类型变量当做布尔类型使用，但是Go 语言禁止这样做。

切片 []T

切片（slice）是Go 语言最常用的类型之一，比数组更常用。切片建立在数组之上，但解决了数组长度固定的缺陷，提供动态扩容的能力。

切片的底层数据结构

切片不是单纯的指针，而是一个描述符，包含三个字段，在64位系统上占24字节：

  • len：你当前能访问到的元素范围（索引 0 到 len-1）。
  • cap：底层数组实际分配的大小（索引 0 到 cap-1）。cap >= len 恒成立。

  • 容量够用时（cap > len）：修改原数组
  • 容量不够用时(cap == len）：脱离原数组

容量不够触发扩容时，s的底层数组会新分配一块扩容的新空间，原数组/切片的底层数组仍然是原空间，之后对切片操作不影响原数组/切片。

像这样，向切片s添加元素elem。

append 执行时，Go 运行时会在底层判断目标切片的 容量（cap） 是否够用，分为两种情况：

  • len(s) < cap(s)（容量充足）：

    • 操作：直接将新元素写入底层数组当前len索引位置。
    • 结果：len增加1，cap不变
    • 如果其他切片和当前切片共享底层数组，追加操作会修改其他切片可见的内容。

  • len(s) == cap(s)（容量耗尽、扩容）：

    • 操作：
      1. 在堆内存中分配一个全新的、更大的底层数组
      2. 将旧底层数组中的所有元素拷贝到新底层数组
      3. 将新元素写入新数组的末尾
      4. 将切片的ptr指针指向新数组
    • 结果：新的len和cap更新，旧切片与新切片彻底脱离底层共享关系。

  • tips：扩容策略：扩容时，新容量（cap）并不是简单地翻倍，而是根据元素大小动态计算，以平衡内存分配次数和空间浪费：

    • 当cap < 256时，新cap ≈ 2 * 旧cap（翻倍）
    • 当cap >= 256时，增长比例逐渐趋缓，直到 ≈ 1.25倍

  • 使用 append 删除索引为i的元素

    • i为0（第一个元素）
  • i为len(s) - 1（最后一个元素）
  • i为其他元素时

注意底层数组变化：s = s[1:]像这样，仅仅是移动指针使元素对于s不可见，元素空间没有释放，如果后续append扩容重新分配底层数组，此时会被GC回收。s = append(s[:i], s[i + 1:]...)像这样，是将底层数组i索引后的元素向前移动覆盖，数组末尾元素没有变化也没有释放。

包间可见性

Go 可以通过 import 引入其他包，但是 Go 没有像 C++ 类这种数据结构，也没有publish、private这种控制可见性的关键字。那么 Go 怎么控制可见性做到对外接口简洁呢？

Go 通过标识符的首字母大小写来决定可见性，这是语言层面强制实施的。

标识符的首字母大写表示导出（Exported），对外部包可见；首字母小写表示未导出（Unexported），仅在当前包可见。

这个规则适用于所有包级别的标识符，即声明在函数外部的元素，包括：

  • 变量 (Variables)：包级变量（全局变量）
  • 常量 (Constants)
  • 函数 (Functions)
  • 类型 (Types)：如使用 type 定义的结构体（struct）、接口（interface）等
  • 结构体字段 (Struct Fields)
  • 方法 (Methods)

注意：包间可见性不是文件间可见性，Go 代码按包组织，同一包内的不同文件可以正常访问、使用未导出（首字母小写）的标识符。

fallthrough（强行穿透）

前面说到 Go 默认自带 break，匹配一个case后退出，但如果你非要执行下一个 case，必须显式写上 fallthrough。注意：fallthrough 不会判断下一个 case 的条件，直接无条件执行它的代码块。

泛型

泛型让你写出“适配多种类型，但保留类型安全”的代码，编译时确定类型，不需要断言。
如果能用泛型，就不要使用空接口。
